# RB-08 · TLS Certificate Renewal

## Alerts

Monitoring alerts 30 days prior to the expiration of any public certificate and re-alerts with priority P2 7 days before expiration.

## Renewal

Customer portal certificates are issued by DigiCert using the corporate account. Generate the CSR with a minimum RSA key size of 2048 bits and upload it to the provider's portal.

## Installation

Install the certificate and intermediate chain on the load balancer lb-ext-01 and verify with an external SSL test that the rating is A or higher.
