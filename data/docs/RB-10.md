# RB-10 · Remote Access VPN Failure

## Symptoms

Remote users are unable to connect to the GW-VPN-02 concentrator or are disconnected every few minutes.

## Diagnosis

Check if the number of active tunnels has reached the 250 simultaneous user license limit and if the VPN portal certificate is still valid.

## Temporary Solution

Enable the alternate concentrator GW-VPN-03 and inform users of the alternate address vpn2.operadora.example. Prioritize access for finance and the service desk.
