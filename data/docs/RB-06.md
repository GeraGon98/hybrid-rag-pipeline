# RB-06 · Label Printer Failures on Platforms

## Symptoms

Zebra ZT411 thermal printers print labels in white, misaligned, or do not receive jobs from the WMS.

## Quick Fix

Recalibrate the media sensor by holding down the pause and cancel buttons for 2 seconds. If printing in white, check that the roll is thermal transfer and not direct thermal.

## Print Queue

If jobs are not arriving, check the PRN-ANDEN print queue on the print server and restart the spooler service. Replacement printers are located in the IT warehouse, shelf 4.
