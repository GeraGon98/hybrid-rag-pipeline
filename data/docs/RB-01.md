# RB-01 · Orion ERP Outage

## Symptoms

Users receive the ORN-503 error when logging into Orion ERP or order screens hang for more than 60 seconds. The Zabbix monitor triggers the ERP-HEALTH alert in red.

## Diagnosis

Check the status of the orion-app service on the erp-app-01 and erp-app-02 nodes with systemctl status orion-app. Review the database connection pool: if it exceeds 180 out of 200 connections, the bottleneck is the database and not the application.

## Recovery

Restart the node with the highest memory usage first, never both at the same time. If the error persists after two restarts, activate contingency mode: orders are captured in the backup sheet and loaded with the ORN-IMPORT job upon service restoration.

## Scaling

If the outage lasts more than 30 minutes, a P1 incident is declared and a case is opened with OrionSoft according to the SLA-D. The on-call manager notifies sales and the distribution centers.
