# RB-02 · Primary MPLS Link Failure

## Symptoms

Branch offices lose access to ERP and WMS simultaneously, while local internet remains functional. The border router rt-core-01 shows the interface Gi0/1 in a down state.

## Diagnosis

Ping the NetLink gateway at 10.20.0.1 and execute traceroute from rt-core-01. If the last responding hop is the provider's equipment, the failure is on NetLink's side.

## Switch to Secondary Link

Traffic reroutes through the IPsec tunnel over Telcom Express internet link (SLA-A). The switch occurs automatically via BGP within less than 3 minutes; if it does not occur, manually lower the MPLS route priority using the command documented in the network appendix.

## Report to Provider

Open a ticket with NetLink at 800-555-0142 indicating the MPLS circuit ID MPLS-NL-7781. The SLA-B contract obliges NetLink to respond within 30 minutes for total outages.
